# Post-campaign decisions and evaluator qualification plan v1

Status: **prepared for owner/scientific review; no new study launched**.
This plan follows the frozen 240-assignment closeout and the explicitly
unblinded source-mechanism pre-review. It is not a retrospective preregistration.

## Completed work

- Freeze all 240 original outcomes and the evidence chain.
- Publish only the allowlisted aggregate and bounded interpretation.
- Prepare metadata-masked review of all 238 final sources, with separate operator
  mapping and assistant proposals; preserve the two missing submissions.
- Audit named mutation syntax, list receivers and all 36 in-place source flows
  without candidate execution. Retain human adjudication as pending.

## Gate 1: human mechanism adjudication

Review all available sources against the original four-link definition. Use the
masked packet before examining outcomes, operator mapping or assistant draft.
A second independent reviewer should adjudicate positives and uncertain cases;
any negative-sampling audit must be selected prospectively and stratified across
task/model/arm, including successful and unscored sources. Pending or uncertain
judgments are not negatives. Record reviewer identity/type, source hashes,
line references and scope limitations. Assistant proposals remain separately
identified even if a later reviewer agrees with them.

Decision:
- If harmful baseline mutations are confirmed and differ across A/D, estimate
  that mechanism contrast alongside full-protocol success and uncertainty.
- If baseline mutations remain unobserved, this corpus cannot establish that D
  prevented them. Report the style shift separately; do not change the endpoint.
- If evidence remains insufficient, retain an inconclusive mechanism result.

## Gate 2: independently qualified future evaluator

The active factory-assessment-confirmation-v1 route and its observers, scoring,
thresholds, data and all original verdicts remain frozen. A prospective evaluator
revision must receive a new explicit identity. No future receipt is relabeled as
an original assessment.

The [qualification matrix](confirmation-next-evaluator-controls-v1.json) specifies
required controls and current status. The next implementation must demonstrate:

1. **Representation coverage:** independent correct compact and partitioned
   water representations, reordered cells/surfaces, reused nested CSG and
   negative gap/overlap/unbounded controls. Correct fixture recognition must not
   rely only on finite point agreement. Unsupported proofs remain indeterminate.
2. **Coincident surfaces:** identical effective behavior versus conflicting
   behavior, including the distinction between a coincident geometric plane and
   a surface participating in an actual root face. Do not choose the convenient
   boundary type when behavior is unresolved.
3. **Source-domain semantics:** supported cell/material constraints, equivalent
   renumberings tied to physical regions, wrong-domain negatives, fissionability
   and rejection-strategy requirements, and unsupported encodings. A known
   mismatch stays visible beside unknown properties. Support must follow actual
   OpenMC sampling behavior rather than literal reference cell-ID equality.
4. **Regression and evidence integrity:** unchanged physical requirements and
   declared numeric margins; positive and negative controls for receipt tampering,
   cleanup, budget exhaustion, source/provenance mismatch and unsupported syntax.
   No observer control grants generic geometry validity or scientific qualification.

Use independently authored controls in isolated XML-only workers/native
qualification where needed, with no LLM generation. Check the next worker's
identity and retained evidence before collecting new study outcomes. The matrix
is a qualification specification, not a passed implementation or native result.

Any later uniform comparison of evaluator versions on the retained corpus needs
a separate explicit reassessment authorization and a new artifact/version.
The original 202/20/18 result remains visible. Never repair candidates or
selectively rescore only favorable unknowns.

## Gate 3: select the next research question before new calls

Candidate question: does the fixed procedure reduce **demonstrated damaging
shared-region mutations** on independent task families, and does that improve
complete protocol success within each agent configuration?

Current source observations are now development evidence. They must not be
reused as unseen confirmation after changing the procedure or choosing favorable
subgroups. A/D with unchanged tools tests provided guidance. A length-matched
additional-guidance control is needed to isolate domain content from additional
context; spontaneous skill selection requires a separate E comparison.

Before freezing a new manifest, settle:
- A practically relevant success/mechanism difference and whether precision or
  hypothesis testing is the objective.
- Independently reviewed task families and controls that provide genuine
  opportunities for reuse without prescribing operators or forcing an error.
- Task-level uncertainty handling, nested generations, model-specific primary
  contrasts, multiplicity and unknown/missing-outcome analyses.
- Sample-size justification using task variation and expected mechanism incidence;
  the old 240-slot accounting is not a power calculation.
- Fixed provider setups, task/reference/data/worker/skill identities, randomized
  execution order, budgets and operational incident policy.

Gate 1 may instead motivate studying representation-dependent assessability or
a targeted deterministic construction diagnostic. Choose and version that
question before implementation and new calls. Extra authoring budget is not
currently indicated by the observed twelve-request/88.4-second maxima; it would
be a separate intervention if studied.
