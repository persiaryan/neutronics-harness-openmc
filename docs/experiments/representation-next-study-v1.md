# Next scientific study: proposed protocol, not launched

This proposal follows the representation-evaluator development work. It does
not authorize provider calls, set a launch budget, or confer scientific approval.
The 240-assignment A/D corpus remains frozen at 202/20/18. It is development
evidence for any procedure designed after seeing it.

## Scientific question and testable invariant

For the supported class of OpenMC models, does independent final assessment
preserve its verdict when the same material field, accepted source law and
effective boundary behavior are expressed differently, while still detecting
specified changes to those objects?

The invariant is semantic: renumbering cells or rewriting a Boolean complement
must preserve the required physical model. Equal CSG volumes alone are
insufficient: coincident conflicting boundaries can change transport. Equal
spatial support alone does not establish an arbitrary joint source law.

The immediate scientific contribution is a measured qualification of the
assessment instrument. A later A/D comparison can ask whether the supplied
region-ownership procedure improves independently assessed construction, once
the measurement procedure and its coverage are fixed.

## Development milestone

Twelve reference packages are explicitly requalified from five retained native
runs each. Original physical/numerical evidence is reconstructed rather than
rerun or relabeled as new transport. Fresh v3 boundary and source inventories
are required. The intentional point-source initialization control retains its
own required law; it is not tested as a uniform proposal.

Four fixed operator controls exercise the entire prospective candidate route:
compact wrapper geometry, cell-selected fuel source, wrong particle count,
and an unsupported source energy restriction. The expected outcomes and source
hashes are saved before execution. V2 and v3 fidelity are compared against the
same exported XML and verified native calculation. This isolates changes in
assessment; it supplies no replication of numerical transport or agent study.

The existing 16 geometry and 14 source controls supplement these four tests.
They are development controls authored by the implementation assistant.
Independent human review and new controls remain necessary for an independent
measurement study.

## Proposed independent qualification

1. Have a nuclear-modeling reviewer adjudicate the public task requirements,
   literal control oracles, source laws and coincident-surface interpretation.
   Record reviewer identity, disagreements, evidence and unresolved questions.
2. Have a different author construct a sealed control corpus before the
   evaluator author receives its answers. Include new dimensions, compositions
   within the declared catalog, equivalent encodings, positive-volume defects,
   and intentionally unsupported cases. Fix the support envelope in advance.
3. Freeze evaluator code, runtime/data, corpus, analysis and resource limits.
   Execute every planned slot once. Preserve timeouts, unsupported cases and
   evidence incidents; do not replace them with successful reruns.
4. Compare both evaluator versions on each identical model. Report equivalent
   family verdict agreement, coverage, detected defects, false acceptances,
   false rejections, unknowns, evidence incidents and runtime. Preserve
   denominator counts by family and defect type.
5. Report a newly exposed limitation as a result of this fixed study. Any repair
   starts another development revision and requires further unseen controls.

Control variants from the same geometric/source family are dependent. Report
family-level results and raw counts. A proportion on this deliberately
constructed corpus estimates performance on that corpus, not prevalence among
all possible OpenMC models or all agent outputs. Statistical intervals require
an explicitly sampled population and a justified family-level design.

## Later agent comparison

Before launch, fix new task families and their independently qualified references,
the A/D intervention, model settings, tools, time/request limits, assignment
order, stopping rules, primary endpoint and analysis. Keep references and
grading observations outside authoring containers. D must be described as a
preloaded procedure if that is the implemented intervention.

The primary endpoint is all-assigned, independently verified complete protocol
success within the qualified envelope. Report model nonconformity, incomplete
assessment and provider/infrastructure incidents separately. Partial scores,
mechanism reviews and resource usage are secondary. Do not treat an unknown as
correct, a provider incident as a scientific model failure, or a syntax pattern
as a demonstrated damaging mutation.

Analyze each model setup separately. Task families, rather than repeated runs
of one task, determine generalization. Specify the smallest relevant benefit
before choosing the number of independent task families and repetitions.
Use task-level paired differences or a justified hierarchical model; examine
precision/power under a declared range of within-task dependence. The previous
240-slot layout is not a justified sample-size default. No sample size or
provider budget is accepted by this document.

## What the project can establish

| Observation | Supported conclusion | Further evidence needed |
|---|---|---|
| Controlled equivalent encodings receive the same qualified verdict | Representation stability within the exercised support envelope | Independent new families for broader claims |
| A planted defect has a retained counterexample | That requirement is refuted in that model | Exhaustive geometry validity remains outside finite probes |
| Native outputs agree within existing screens | Computational agreement under those screens | Threshold calibration and physical validation remain separate |
| A/D rates differ on a new fixed study | A study-specific intervention estimate with stated uncertainty | Generalization requires adequate independent tasks and settings |
| A source uses `&=` or a procedure avoids it | An observed construction pattern | A causal damaging chain and independent mechanism adjudication |

The immediate readiness decision is technical qualification for further
development. Conference submission scope, independent scientific review,
unseen corpus authorship, sample size and provider budget remain owner decisions.
