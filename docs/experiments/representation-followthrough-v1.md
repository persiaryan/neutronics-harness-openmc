# Representation qualification follow-through

This milestone extends the initial representation-evaluator controls with
explicit reference requalification, a fixed native integration matrix and a
proposal for the next independent study. It makes no provider calls and does
not reassess the original 240 assignments.

## Reference requalification

The twelve new packages retain the five original numerical executions per task.
No reference transport is represented as newly run. Admission first verifies
the predecessor seal and complete file inventory, unchanged task/version,
rubric and numerical protocol, exact variant generation, original exports,
physical observations, native process/statepoint/history evidence, runtime and
nuclear data. No legacy identity exemption is added.

Each copied package preserves its predecessor manifest, seal and qualification
report. Fresh v3 boundary and source-domain inspections run against all five
original XML exports. Four uniform-source runs must pass prospective physical
checks; the intentional point-source initialization control retains its own
required source law and the full existing verifier. New package seals bind the
current implementation, requalification controller and reference verifier.

The separate read-only review reconstructs all twelve packages. The aggregate
summary was also compared with their twelve retained review records. This is
requalification of 60 retained calculations with 120 fresh XML observations,
not a numerical replication or independent human scientific approval.

Critical functions:

- `evaluation.representation.references.predecessor`: provenance and unchanged
  task/criteria admission.
- `reconstruct` and `experiments.confirmation_reference_review.review_runs`:
  original five-run reconstruction and exact variant binding.
- `observe` / `compare`: new isolated XML observations and prospective fidelity.
- `verify`: original artifact preservation, current seal and observation replay.

## Fixed end-to-end development matrix

`evaluation.representation.development.plan` freezes four source hashes,
expected outcomes, selected reference hashes, implementation/controller identity,
four-call transport ceiling, 1,800 seconds per transport, and zero retries before
any execution. Candidate constructors are executed only in the isolated factory.

| Control | Required prospective outcome | Purpose |
|---|---|---|
| Compact wrapped geometry | Conforming within protocol | The equivalent compact complement must remain assessable |
| Fuel cell as source domain | Conforming within protocol | Equivalent cell restriction needs no redundant explicit fissile flag |
| 5,000 particles instead of required 10,000 | Nonconforming | Preserve a known sampling requirement violation |
| Additional source energy restriction | Indeterminate, null score | Unsupported source semantics must not earn conformity |

All four native assessments and their separate retained-evidence reconstructions
passed. The compact geometry and cell-selected source each changed from a null
legacy score to 100/100, with conformity established within the protocol. The
particle-count control remained nonconforming at 75/100 in both versions; its
numerical equivalence screen also failed, so the score change must not be
attributed solely to the sampling check. The unsupported restriction retained
a null score in both versions, while the prospective evaluator left only the
source group unassessed instead of blanking all four settings groups.

Every run uses independent final export, legacy scientific inspection, v3
boundaries, source-domain observation, native transport, scoring and retained
verification. The legacy comparison executes v2 boundaries against the same
final XML and reuses the same verified transport/numerical evidence. It measures
the change in assessment without a second numerical realization.

The [machine-readable result summary](representation-followthrough-results-v1.json)
records actual results and retained-report digests. It contains no reference
constructors, private reference numerical answers, raw traces or local paths.
Per-control wall times distinguish full prospective assessment, v2/v3 boundary
inspection and the additional source phase. They are single-run observations
on the retained local runtime, not a controlled performance benchmark.
The additional source phase took 2.337 to 2.957 seconds on these four runs;
the predeclared phase limit remains 120 seconds.
The initial [qualification snapshot](representation-evaluator-results-v1.json)
retains its original `not_run` fields for the earlier milestone.

## Reproduction with operator evidence

Use an explicitly selected twelve-task operator reference index. Inputs and
outputs are private; each output directory must be fresh.

```sh
python3 -B -m evaluation.representation.references \
  --references "$ORIGINAL_REFERENCE_INDEX" --output scratch/representation-references \
  --data-index "$DATA_INDEX"
python3 -B -m evaluation.representation.references --verify \
  --references scratch/representation-references/references.json \
  --output scratch/representation-references --data-index "$DATA_INDEX"
python3 -B -m evaluation.representation.development \
  --references scratch/representation-references/references.json \
  --output scratch/representation-development --data-index "$DATA_INDEX"
python3 -B -m evaluation.representation.development --verify \
  --references scratch/representation-references/references.json \
  --output scratch/representation-development --data-index "$DATA_INDEX"
```

The reference command reconstructs the selected package bytes; it does not
discover alternative references or repair a blocked one. The development command
stops on an integration/evidence incident without replacing the consumed run.
The public synthetic XML and native-law controls remain separately reproducible
without operator reference constructors.

## Scientific interpretation and next gate

An improvement on these development controls establishes bounded technical
measurement capability. It does not estimate evaluator accuracy over all OpenMC
models, the benefit of D, global geometry validity, or physical safety. The
same AI assistant authored the controls and implementation; human review remains
pending. Inherited numerical thresholds remain uncalibrated diagnostic screens.

The [next-study proposal](representation-next-study-v1.md) fixes a question about
representation stability, defines the measured objects and outcome denominators,
and separates new independent controls from reused development cases. A later
agent study needs new tasks, independent reference/control review, a justified
sample size, frozen analysis and an explicit provider budget before launch.

The full portable suite passed 720 tests. Separate reconstruction also verified
the earlier 16 geometry controls, 14 source controls, ten native source-law
controls and four native crossing controls. The original campaign seal still
verifies 55,781 files with its original aggregate digest. These reconstruction
checks are not new executions of the earlier native controls.
